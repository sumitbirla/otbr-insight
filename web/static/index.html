How the network fits together

Thread is a low-power IPv6 mesh. Mains-powered devices can become routers, battery-powered devices usually attach as children, and one router acts as leader for the current partition. The border router connects that mesh to Ethernet or Wi-Fi without becoming a central hub for local Thread traffic.

KEY CONCEPTS

What the dashboard is showing

Device roles

Leader, router, and child describe what a device is doing now—not its permanent identity.

Parent relationships

Children use one parent router to enter the mesh. The Devices map shows relationships OTBR can report or infer.

Thread addresses

Mesh-local addresses stay inside Thread; OMR addresses are designed to be reachable through a border router.

The border router

OTBR connects the Thread mesh to the wider IPv6 network and exposes the status used by this dashboard.

Partitions

Nodes that can reach one another form a partition with one leader. Separated groups run as their own partitions and merge again when they reconnect.

RLOC16

A short address that encodes where a node currently sits in the mesh: the upper bits identify its router, the rest identify children under it.
